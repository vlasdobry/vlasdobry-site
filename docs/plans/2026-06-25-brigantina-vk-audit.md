# VK-разбор сайта отеля «Бригантина» — план реализации

> **For the agent:** REQUIRED SUB-SKILL: Use $executing-plans to implement this plan task-by-task.

**Goal:** Подготовить фактологически проверенный VK-пост и пять карточек о неверной иерархии H1 на сайте отеля «Бригантина».

**Architecture:** Все материалы хранятся в `docs/content/vk-audits/brigantina-gelendzhik/`. Официальный сайт является первичным источником; HTML-карусель служит исходником для PDF и отдельных JPG.

**Tech Stack:** Markdown, plain text, HTML/CSS, Puppeteer, PyMuPDF/Pillow.

---

### Task 1: Зафиксировать факты

- Создать `audit-notes.md`.
- Повторно получить главную страницу и сохранить title, description, H1/H2/H3, raw HTML четырёх H1 и название отеля в H3.
- Явно отметить динамический характер дат формы.

### Task 2: Написать VK-текст

- Создать `post.md` и `vk-ready.txt`.
- Использовать повествование «в интерфейсе всё понятно, в HTML роли перепутаны».
- Добавить официальный URL отеля и ссылку на Health Score.
- Применить `$localizer`; исключить формулы прошлых постов и неподтверждённые последствия.

### Task 3: Создать карточки

- Создать `carousel.html` из пяти слайдов 1080×1350.
- Использовать тёмную палитру Web4Hotel, жёлтый акцент и крупные числовые элементы.
- Не использовать стоковые изображения и AI-графику.

### Task 4: Экспорт и проверка

- Сгенерировать `carousel.pdf` и пять JPG в `slides/`.
- Проверить размеры, число страниц, переполнение DOM и совпадение текста с audit-notes.
- Сравнить устойчивые фразы с предыдущими VK-публикациями.
